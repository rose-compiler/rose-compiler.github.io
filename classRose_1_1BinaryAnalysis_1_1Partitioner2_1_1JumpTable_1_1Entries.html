Rose::BinaryAnalysis::Partitioner2::JumpTable::Entries Class Reference

Description

Entries in a jump table.

Entries are transformed to target addresses in a couple different ways:

  • The target address is the table entry plus some (nominally zero) offset.
  • The target address is the table entry plus some (nominally zero) offset plus the starting address of the table.
