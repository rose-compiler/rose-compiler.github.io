Detailed Description

JVM LocalVariableTypeTable attribute.

The LocalVariableTypeTable attribute is an optional variable-length attribute in the attributes table of a Code attribute (4.7.3). It may be used by debuggers to determine the value of a given local variable during the execution of a method. See section 4.7.14 of the JVM specification.
