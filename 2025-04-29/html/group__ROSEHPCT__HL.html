Detailed Description

The ROSE-HPCT End-user Interface defines an interface to the ROSEHPCT for use by "end-users."

For a simple example, see examples/test_highlevel.cc .

◆ getProfileOptions()

FilenameList_t RoseHPCT::getProfileOptions ( std::vector< std::string > &  argvList)

Get HPCToolkit profile data options from the command-line.

This routine extracts command-line flags of the form:

-rose:hpct:prof profile_data.xml

where "profile_data.xml" is an HPCToolkit-generated XML file containing profiling data in HPCViewer profile scope tree format, and returns a list of all specified profile data filenames.

See also
RoseHPCT::getEquivPaths, RoseHPCT::loadProfilingFiles

◆ loadProfilingFiles()

RoseHPCT::ProgramTreeList_t RoseHPCT::loadProfilingFiles ( std::vector< std::string > &  argvList)

Loads HPCToolkit XML or GNU gprof text profiling data given on the command-line.

This routine processes the given command-line arguments, extracting options that specify what HPCToolkit XML data files or GNU gprof line-by-line text file to use and how to interpret them. For more information on the flags recognized, see RoseHPCT::getProfileOptions and RoseHPCT::getEquivPaths .

Returns
A list of HPCToolkit "profiled program trees" which store the profile data in an abstract form that mimics the program structure.
