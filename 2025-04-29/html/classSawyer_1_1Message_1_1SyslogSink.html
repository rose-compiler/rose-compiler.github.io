Allocating constructor. Constructs a new message sink that sends messages to the syslog daemon. The syslog API doesn't use a handle to refer to the syslog, nor does it specify what happens when openlog is called more than once, or whether the ident string is copied. Best practice is to use only constant strings as the ident argument.
