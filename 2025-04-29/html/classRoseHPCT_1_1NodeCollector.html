Detailed Description

template<class T>
class RoseHPCT::NodeCollector< T >

Simple class to collect nodes in the Sage III IR.

The template type T should be a child class of SgLocatedNode.

Create a node collector, initializing it to identify nodes that of type T whose physical line numbers lie between a specified interval (b, e) inclusive. Call 'traverse' on a particular root node to initiate the search. On return, use beginMatch/endMatch to iterate over matching nodes.
