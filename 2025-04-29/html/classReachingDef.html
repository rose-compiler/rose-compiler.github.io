enum ReachingDef::Type

PHI_FUNCTION 

'Fake' definition that joins two different reaching definitions.

ORIGINAL_DEF 

Definition for the actual variable in question, not a parent or child.

EXPANDED_DEF 

Definition for the parent or child of this variable. (E.g. if x.b is the variable in question, this def could be for x or x.b.a).
