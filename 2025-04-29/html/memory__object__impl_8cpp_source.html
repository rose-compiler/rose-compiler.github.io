237  //
238  //Think the following example:
239  //-------------------
240  //struct A { int i; int j;} ;
241  //struct A a1;
242  //struct A a2;
243  //
244  //int x = a1.i + a2.i + a2.j + a2.j;
245  //-------------------
246  //
247  //1. most coarse: treat any references to struct A's instance as the same to struct A.
248  // This means to treat a1.i, a2.i, a2.j, a2.j as the same access to struct A.
249  // There is only one memory object for all a1.i, a2.i, a2.j and a2.j.
250  //
251  //2. finer: distinguish between different fields of A. But the same field to all instances will be treated as the same.
252  //
253  // Now a1.i and a2.i will be modeled as A.i
254  // a2.j and a2.j will be modeled as A.j
255  // There are two memory objects for all a1.i, a2.i, a2.j and a2.j.
256  //
257  //3. Finest : distinguish between not only the fields, but also the instances.
258  //
259  // a1.i, a2.i, a2.j, a2.j will be represented as four different objects.

262  // This means type declarations (e.g. struct A{}) without declared instances (struct A a1; )will not have the corresponding memory objects.
