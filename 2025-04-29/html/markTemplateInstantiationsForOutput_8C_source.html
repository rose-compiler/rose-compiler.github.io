959  {
960  // This function marks template instantiations for output within code generation.
961  // By isolating the control over the output of template instantiations we simplify
962  // the design of the unparser (code generator). Note also that while template
963  // specializations appear as template declaration in their syntax, they are functionally
964  // just explicit template instantiations.
965 
966  // This function has multiple phases:
967  // 1) Locate all template instantiations that are referenced in the source file.
968  // 2) Iterate over the list of instantiatied member functions
969  // a) if it is a specialization then mark it for output
970  // b) if the associated template definition appears in the source file then
971  // 1. if it is defined in the class then mark the instantiation for output
972  // EDG does not include the definition of member function in the string
973  // representing the template definition.
974  // 2. if it is not defined in the class then don't output the instantiation.
975  // FOR G++ 3.3.x
976  // 3. Build a prototype for the member function and insert it into the correct
977  // scope (global scope should work).
978  // FOR G++ 3.4.x and likely 4.x (also works for 3.3.x)
979  // 4. Move the definition to appear after the class instantiation's definition
980  // 3) Iterate over the template function instantiations
981  // a) if it is a specialization then mark it for output
982  // b) if the associated template definition appears in the source file then
983  // do NOT mark it for output.
984  // 4) Iterate over the template class instantiations
985  // a) if it is a specialization then mark it for output
986  // b) if the associated template definition appears in the source file then
987  // do NOT mark it for output.
