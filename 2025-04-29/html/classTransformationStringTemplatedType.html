Function to enforce preconditions (constraints) on the values used within the constructor's interface.

Note that we automatically change some of the input specifications to permit the simplified automatic testing of all the permutations associated with new strings added to all locations in a scope and for all scopes. Some combinations of relative scope and relative location simply do not make sense!. This function modifies the scope and location so that they make sense.
