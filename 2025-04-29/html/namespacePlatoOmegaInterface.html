Detailed Description

This Header file defines the interface to the Plato and Omega dependency testing libraries.

Variables or functions that are specific to one of the libraries will have Plato or Omega in the name.

Classes and functions have the first letter of each word capitalized with no underscores.

typedefs are normally all capitalized with underscores between each word.

Class variables start with an underscore and have no capitals.

Function variables do not start with an underscore but still have them between words, and there is no capitals.
