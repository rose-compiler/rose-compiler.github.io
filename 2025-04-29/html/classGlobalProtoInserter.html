Detailed Description

Traversal to insert a new global prototype.

This traversal searches for the first non-defining declaration for a given function definition, and inserts a new prototype of that function into global scope. In addition, it fixes up the definition's first non-defining declaration field to point to the new global prototype.

The traversal terminates as soon as the first matching declaration is found by throwing an exception as a string encoded with the word "done". The caller must ensure that any other matching declarations have their first non-defining declaration fields fixed up as well.
