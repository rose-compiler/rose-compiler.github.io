Detailed Description

template<class VT, class IT = size_t>
class Trees::Tree< VT, IT >

Templated tree data structure (a tree node), parameterized by the type of the value (VT) stored at each node and type for indices (IT) used to 'name' the child nodes.

Both IT and VT should have value semantics. This tree abstraction provides interfaces to create, destroy trees, retrieve and set child nodes iterate children nodes
