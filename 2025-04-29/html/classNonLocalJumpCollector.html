Detailed Description

Traversal to collect non-local jumps.

In particular, This sub-tree traversal begins at the given node, 'root', and descends to collect the following statements:

  • All return statements not enclosed by any function definition within 'root';
  • All break statements not enclosed by any loop or switch;
  • All continue statements not enclosed by any loop.
