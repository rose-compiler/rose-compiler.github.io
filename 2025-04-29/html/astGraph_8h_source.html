159 /*******************************************************************************************************************************
160  * The class
161  * class DataMemberPointersToIR
162  * implements two different ways of constructing a graph from the AST.
163  * * The memory pool traversal which is why the class inherits from ROSE_VisitTraversal
164  * * Whole AST traversal through traversing on nodes
165  * This design decision is peculiar out from a inheritance perspective, but makes sence to
166  * bridge between the iheritance style of Marcus and an STL algorithm style. Caveats:
167  * * one member functions is only used by the memory pool traversal
168  * -visit(..)
169  * The member function generateGraphFromMemoryPool(..) is required to achieve
170  * STL style algorithms where the bace-class uses implemenatation by virtual functions.
171  * Great things:
172  * * avoid duplicate implementation
173  * * allows a very simple implementation
174  ******************************************************************************************************************************/
