Returns a new outlined function containing a deep-copy of s.

Create a function named 'func_name_str', with a parameter list from 'syms'.

This function only creates and returns an outlined function definition, f. Although it sets the scope of 'f' to be the first scope surrounding 's' that may contain a function (or member function) definition, it does not insert 'f' into that scope.

This function is an "inner" outlining routine which does not properly handle non-local control flow. To outline statements containing non-local flow, a caller should instead call Outliner::outline(), which preprocesses non-local control flow appropriately. See Outliner::transformNonLocalControlFlow() for more details.

pdSyms is used to store symbols which must be replaced with their corresponding pointer dereferencing if replaced during outlining. Used to support -rose:outline:temp_variable It is also used to support struct wrapper parameter to indicate if a variable is stored by its address (not value) in the wrapper.

// pSyms are OpenMP private variables, or dead variables (neither livein nor liveout)

Note: private, firstprivate, reduction variables are handled by OmpSupport::transOmpVariables() They are not in actual use anymore.

Precondition
The statement does not contain non-local control flow.

◆ outline() [1/3]

Outliner::Result Outliner::outline ( SgStatement *  s)

Outlines the given statement. The main programming interface.

This function pre-process the target stmt first and outlines the specified statement, s. It creates a new outlined function definition, f, inserts f into the first scope surrounding s that may contain a function (or member function) definition, replaces s with a call to f, and finally returns f.

It can also does pre-processing only if directed by the internal flag, which is specified by user command line option and processed by commandLineProcessing();

Programmers are expected to tell if a statement is outlineable before calling this function.
