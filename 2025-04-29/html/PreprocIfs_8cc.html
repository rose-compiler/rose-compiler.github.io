static const CPreproc::If::Case* getOpenCase ( const CPreproc::If::Case *  c)
static

Returns the 'if ...' that opens the directive to which this case belongs.

For example, let 'c' be as marked below:

if A // Associated with some case, 'a' // ... #elif B // ... #elif C // Associated with input case, 'c' // ...

Then, this routine returns 'a'.

Returns
A non-NULL result, given a non-NULL input case.

static void prependAtFirstStatement ( PreprocInfoList_t &  D,
SgBasicBlock *  b 
)
static

Inserts the given preprocessing info at the front of the first statement in b.

Precondition
b is non-NULL and has at least 1 statement in it.
Note
This code handles a somewhat esoteric special case in which the statement 's' will not be unparsed, and so any preprocessing information attached to it would also go unparsed. This occurred in CompileTests/Cxx_tests/test2001_09.C, where an implicit return statement (represented explicitly in the tree but unparsed) was being outlined.
