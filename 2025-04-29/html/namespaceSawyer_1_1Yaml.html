◆ ValidateQuote()

bool Sawyer::Yaml::ValidateQuote ( std::string &  input)
static

There is an interior quote, which is OK as long as it is escaped properly:

  • " is escaped by \, e.g. "foo " bar";
  • ' is escaped by ', e.g. 'foo '' bar'.

Notice that the escape character for single quotes is also a single quote. As a result find_first_of will find the escape character for escaped single quotes.
