2 // This implements constant folding using both a conventional
3 // constant folding algorithm and also the work that has already
4 // been done within EDG on the part of the AST generated by the front-end.
5 // 1) Constant folded expression trees saved in the AST are eliminated
6 // simplifying optimizations and a number of analysis operations.
7 // 2) New constant values expression added after the front-end
8 // processing are folded. This simplifies transformations introduced
9 // after front-end processing.
10 // The constant folding is implemented first to eliminate the front-end
11 // constant valued expression trees that have been saved into the AST.
12 // This is done because the PRE had at least one bug specific to nested
13 // application of itself on the saved constant folded expression trees.
14 // So eliminating them fixes this problem at least for now.
