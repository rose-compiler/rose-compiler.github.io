4 /*
5  This file constains the code to fixup the source position information in the AST.
6  By default we store the information that we gather from EDG, however this information
7  is incomplete and misses a number of details that are important within ROSE.
8  Incomplete aspects include (likely because EDG is not trying to support source-to-source
9  details):
10  1) namespaces lack the postion information about the location of the keyword ("namespace").
11  2) constants are often missing source postion information (when not constant folded).
12  Constant folded constants are of course not in the source code and so are marked
13  as compiler generated within ROSE.
14  3) paramter lists (i.e. positions of "(" and ")")
15  4) the location of the ";" is often unavialable (or not properly extracted from EDG,
16  since I think it might be present in come cases).
17 
18  These details aside, EDG is in general extremely good about saving source position information
19  (and in great detail, more detail that we require in ROSE).
20 
21  However, in ROSE we want the start and end of each expression and statement (at least the statements).
22  To get this information we have built a traversal which uses synthesized attributes to compute the
23  farthest ending position of any part of a subtree represented by a statement and we use that for
24  the end of the statement (the same is done for the start of a statement, though this is in general
25  already correct).
26 
27  For expressions this approach would cause the location of operators to be lost, so we still have to
28  address this.
29 
30  Suggestions for better handling of source positoon information in ROSE:
31  1) A number of declarations consist of multiple parts and when we store only the start and end
32  of the construct we miss the positions of the different parts. EDG separates out the positions
33  of the identifier, any specifiers, and the declarator or enum value. We could save this
34  information at the cost of adding to the memory requirements of the AST.
35 
36  */
