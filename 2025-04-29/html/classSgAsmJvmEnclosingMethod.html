Detailed Description

JVM EnclosingMethod attribute.

The EnclosingMethod attribute is a fixed-length attribute in the attributes table of a ClassFile structure (4.1). A class must have an EnclosingMethod attribute if and only if it represents a local class or an anonymous class, see section 4.7.7 of the JVM specification.
