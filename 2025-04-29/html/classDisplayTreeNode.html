Detailed Description

A DisplayNode used to manage a tree.

A DisplayTreeNode is a DisplayGraphNode which has only outputEdges (children) and a dedicated inputEdge (parent)

  • The memory handling is done by the parent node (when parent is deleted the whole subtree, edges and additionalEdges are deleted)
  • each node owns the edges to the childs, parentEdge is deleted by parent
