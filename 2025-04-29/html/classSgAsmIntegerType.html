◆ check()

virtual void SgAsmIntegerType::check ( ) const
overridevirtual

Validate properties collectively.

This method collectively validates the properties of a type since validation is not always possible or convenient when the user modifies an individual property. For instance, when changing the bit fields in a floating-point type, it would be very inconvenient to the user if those properties individually validated there settings because it would require the user to shuffle fields around in such a way that they never overlap. This way, the overlap validation can occur after the user is all done moving the fields.
