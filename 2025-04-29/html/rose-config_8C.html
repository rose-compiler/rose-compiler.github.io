◆ toOldKeyFormat()

std::string toOldKeyFormat ( std::string &  key)

toOldKeyFormat

/brief Converts a Key to the old format

JL (03/24/2018) I changed the default keys to be ROSE_CC, ROSE_PREFIX, etc. They used to be cc, prefix, etc. This was so the rose-config.cfg would not conflict with similar keys when included in a Makefile. To keep the rose-config binary compatible with old code, we now support both on the command line. This function converts the new format to the old format.
