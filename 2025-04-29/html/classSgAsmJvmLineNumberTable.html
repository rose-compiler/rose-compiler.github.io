Detailed Description

JVM LineNumberTable attribute.

The LineNumberTable attribute is an optional variable-length attribute in the attributes table of a Code attribute (4.7.3). It may be used by debuggers to determine which part of the code array corresponds to a given line number in the original source file. See section 4.7.12 of the JVM specification.
